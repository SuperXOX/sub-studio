SUB Studio · 多语种字幕便携版
苹果极简＋粉紫渐变 · Windows 10/11 x64

使用
双击“字幕翻译 Studio.exe”，拖入或添加一个或多个 SRT 字幕。
转繁体：直接点击文件卡片右上方“一键繁体”。使用随包 OpenCC 本机词典，不联网、不登录、不加载 AI。
翻译：选择目标语言及“离线”或“联网 AI”，再点击“开始翻译”。
目标：繁体中文、英文、日语、韩语、泰语、印地语（Hindi）、西班牙语、意大利语。

输出
新字幕直接保存在原字幕所在目录，名称加“_繁体”或“_日语_离线”等目标与模式后缀；重名自动加序号，不覆盖原字幕。
只改正文；保留原序号、时间码、换行、正文行数、格式标签与外侧空白。源字幕时间倒退、重叠或格式错误时拒绝处理。
输出旁的“检查.json”记录结构校验、源文件哈希及阅读速度提示。翻译不会调整时间码。AI 翻译统一输出 UTF-8；本机繁体同时保留 UTF-8 / UTF-16 原 BOM。

模式与质量
离线：自带本地模型和 CPU/Vulkan 引擎，无需网络或账号。默认尝试显卡，失败后使用 CPU；也可勾选“仅使用 CPU”。印地语增加本机英文语义参考步骤，处理稍慢，全程仍在本机。
联网 AI：随包官方 Codex 组件，沿用当前电脑 Codex/ChatGPT 登录与额度，无需填写 API Key。字幕正文、相邻上下文和术语会发送给联网 AI。新电脑或登录失效时点击“登录账号”或“重新登录”，在官方浏览器页面完成登录。
翻译采用简洁自然的口语提示。离线与联网使用不同模型，措辞与语义质量可能不同；联网模式更适合对自然表达要求高的成片。逐句语义不由时间轴校验保证，发布前请结合原音复核。
运行期间不能切换目标或模式，避免同一次任务混用语言。切换目标会重置队列结果状态，各语言缓存独立。

取消与结果
点击“取消”后，已完成的 AI 条目或批次保留在本机缓存，再次处理同一文件可续译。“查看结果”打开最后成功输出的目录，“运行详情”显示进度与错误。
使用时自动生成 data，存放缓存和运行状态。清空缓存需先退出，再删除 data；这会失去续译记录。

移动
先退出软件，再复制或移动整个“SUB Studio”文件夹（完整构建约 3 GB 以上）。模型、引擎、联网组件、OpenCC、图标均已整合到此目录，不要只移动 EXE。
放在可写目录。AI 离线翻译至少 8 GB 内存，推荐 16 GB；繁体词典转换不需要加载大模型。系统需具备 .NET Framework 4.x。
普通使用无需另装 Python、Node、OpenCC 或 Codex App。同机换目录沿用当前登录；换电脑使用联网模式需登录一次。
便携路径已验证到同机另一目录；第二台实体电脑尚未实测。此包用于 Windows x64，不能直接在 macOS 上运行。

目录
models：离线模型。engine / engine-vulkan：本地翻译引擎。online：联网组件。
opencc：本机繁体转换引擎和词典。licenses：组件许可。assets：当前 SUB 标识的 SVG、PNG、ICO。
源码位于开源项目的源码目录。components.json：组件版本与来源。
manifest-sha256.json：固定文件 SHA256 清单，不包含自动生成的 data。

命令行（可选）
& '.\字幕翻译 Studio.exe' --translate --mode offline --target ja --report '.\data\结果.json' 'D:\字幕\影片.srt'
--target 允许 en、zh-Hant、ja、ko、th、hi、es、it；不指定仍为英文。繁体目标始终本机转换。
& '.\字幕翻译 Studio.exe' --check --report '.\data\完整性检查.json'
报告 success=true 表示固定文件与清单匹配。

开发
从开源项目运行 build.cmd 或 scripts\build.ps1；首次构建需要联网下载组件。执行 128 项回归检查后，在 dist\SUB Studio 生成程序。
编译与测试使用系统临时目录并自动清理；改动固定文件后需要刷新完整性清单。
开源源码与生成的便携版分开放置；运行软件只需完整的 dist\SUB Studio 文件夹。
